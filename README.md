# 💰 Smart Daily Expense Tracker

A privacy-first web application designed for students and individuals to track, analyze, and understand their daily expenses using Excel/CSV uploads.
🔗 **Live App:** https://your-app-name.streamlit.app

## 🚀 Features
- Upload monthly expense files (Excel/CSV)
- Category-wise spending analysis
- Daily spending trends visualization
- Smart insights in simple, human-readable language
- Month-to-month expense comparison
- No login or permanent data storage

## 🛠 Tech Stack
- Python
- Streamlit
- Pandas
- Plotly

## 📂 How to Use
1. Download the expense template
2. Fill in your daily expenses
3. Upload the file to the app
4. View dashboards and insights
5. (Optional) Upload a previous month file for comparison

## 🔒 Privacy
This application does not store user data on any server. All analysis is performed during the session, ensuring complete user privacy.

## 🌐 Deployment
Deployed using Streamlit Community Cloud.

## 📌 Use Case
Ideal for college students, individuals, and households who want a simple and privacy-friendly way to analyze spending habits.
